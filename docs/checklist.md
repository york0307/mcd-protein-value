# 报名前自查清单

> 提交 Issue 前逐项打勾。任一「必须项」未满足，报名会被系统驳回。

## 一、仓库文件（必须）

| # | 文件 | 要求 | 状态 |
|:---:|---|---|:---:|
| 1 | `README.md` | 含项目介绍、安装方法、使用示例、目标用户；**文件名不可改动** | ☐ |
| 2 | `CONTEST_DECLARATION.md` | **文件名与内容均不可改动**，直接使用官方原文 | ☐ |
| 3 | `MCP_INTEGRATION.md` | 说明实际使用的 MCP Server / Tool / 调用流程 / 业务价值 | ☐ |
| 4 | `mcp-config.example.json` | 脱敏，**只允许环境变量占位符** | ☐ |
| 5 | `workbuddy.md` | 参加 WorkBuddy 专项奖励时必须提交；**文件名不可改动** | ☐ |
| 6 | 源代码 | 项目主体，形式不限 | ☐ |

## 二、仓库状态（必须）

- [ ] 仓库为 **Public**（公开可访问）
- [ ] 仓库创建时间在 **2025-12-25 00:00 ~ 2026-10-25 23:59** 之间
- [ ] 项目中**真实调用**了麦当劳 MCP（否则直接不符合资格）
- [ ] 项目**真实使用**了腾讯 WorkBuddy（要拿专项奖励的话）

## 三、安全自查（高危）

- [ ] 全仓库**搜不到**任何真实 Token / 密钥 / 密码 / 账号凭证
  ```bash
  grep -rInE "(Bearer [A-Za-z0-9_-]{16,}|sk-[A-Za-z0-9]{20,}|token[\"'=: ]+[A-Za-z0-9_-]{16,})" . --exclude-dir=.git
  ```
- [ ] `.gitignore` 已包含 `.env` / `mcp-config.json` / `*.token`
- [ ] **未**包含他人个人信息
- [ ] 未植入恶意脚本、钓鱼链接、病毒、后门
- [ ] git 历史里也没有提交过 Token（有的话需 rebase 或重建仓库）
  ```bash
  git log --all -p | grep -iE "bearer |token" | head
  ```

## 四、合规自查

- [ ] 项目名称/简介/内容不含违法违规或敏感内容
- [ ] **不**贬低麦当劳品牌，**不**与其他品牌做对比
- [ ] **不**宣扬不健康饮食方式、奢靡浪费、拜金主义
- [ ] 未使用刷 Star 手段（脚本、多账号、串通、买 Star）——**这是取消资格项**

## 五、报名动作

- [ ] 代码已 push 到公开仓库
- [ ] 已在活动仓库按模板发布 Issue（见 `docs/issue-template.txt`）
- [ ] 收到系统的「报名成功」回复
- [ ] 确认仓库 Owner 邮箱可被读取（未公开则需完成 GitHub OAuth 授权）
